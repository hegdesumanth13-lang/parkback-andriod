# Delivery validation

The debug application, JVM tests and instrumentation test APK built successfully with AGP 8.7.3, Gradle 8.9, Kotlin 2.0.21, JDK 17, Build Tools 34.0.0 and Android SDK 35. The app targets 35 and supports Android API 26 and above. All 13 requested features are implemented in the compiled application.

| Check | Result |
|---|---|
| Gradle assembleDebug | Passed. The signed debug APK is included at app/build/outputs/apk/debug/app-debug.apk. |
| Gradle testDebugUnitTest | Five tests passed. They cover coordinate boundaries, invalid GPS input, relative time, walking directions and invalid map destinations. |
| Gradle assembleDebugAndroidTest | Passed. The Android tests cover distance, Room database reopening, replacement, retrieval, deletion and preservation of the active record. |
| Android APK signature verification | Passed with Android SDK apksigner. |
| Physical-device execution | Pending. No device was connected to this build environment. GPS, live marker movement, heading, camera, notification delivery and Maps handoff require the physical-device checklist in README.md. |

The debug build was compiled on Linux. The included Windows Gradle wrapper was generated by Gradle. Android Studio import on Windows and installation on a handset still require verification. The APK is debug-signed for local installation and hackathon demonstrations.
